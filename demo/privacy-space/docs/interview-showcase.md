# Miloco 隐私空间动画演示

## 项目定位

这是 Miloco 穿搭 Agent 的独立合成数据展示原型。页面把房间、设备状态、匿名人数、穿搭建议和隐私处理状态显示为低细节空间视图，供面试演示系统边界与可测试性。

动画页面只消费结构化数据。当前项目没有真实摄像头输入、模型调用、音箱播报、1812 接线或家庭照片处理，不能作为真实隐私过滤已完成的证明。

## 设计

输入是合成 `DemoState`：房间和证据级别、设备类型与在线状态、匿名人数、穿搭候选，以及单帧隐私摘要状态。页面不接收 owner ID、设备 DID、token、原始图片路径或模型原文。

独立的 `PrivacyFrameProcessor` 以合成文件验证处理边界：只接受受控临时根目录下的输入文件；成功和处理失败后删除输入；越界文件不操作；删除失败返回固定错误码，并且不报告已清理。浏览器里的“回放合成处理结果”按钮只切换演示状态，不执行文件处理。

## 三分钟演示

1. **0:00–0:30** 展示合成数据来源，说明画布中没有实时视频。
2. **0:30–1:10** 查看客厅、卧室、匿名人数和设备状态，解释“已确认”和“推断”的区别。
3. **1:10–1:50** 点击“回放合成处理结果”，说明浏览器展示的是测试后的状态；指出清理失败时会返回固定错误码。
4. **1:50–2:30** 查看合成穿搭建议，说明库存事实和最终穿着需由用户确认。
5. **2:30–3:00** 展示测试、构建、静态烟测与桌面/手机浏览器验收结果，再说明真实设备仍需单独验收。

这些是独立合成原型的证据，不代表 Miloco 真实摄像头隐私处理或穿搭语音、视觉闭环已通过。

## 公开展示素材

文章、截图和录屏仅展示合成房间与衣物。发布前检查画面和文件元数据，不包含真实家庭照片、人物、住址、设备 ID、token、原始帧或私有部署信息。建议把项目描述为“家庭感知的隐私抽象与穿搭展示原型”，不要称为“实时视频匿名化产品”。

## 后续接入

桌面与手机视口验收已完成。下一步设计 Miloco 的只读结构化 adapter。真实摄像头单帧处理需沿用宿主的用户触发、预算、临时媒体清理和低敏感度审计门，不能从这个动画视图直接读取摄像头或数据库。
