# 穿搭建议 Agent 知识库种子

更新时间：2026-07-03 22:05 北京时间

## 目标

把已经跑通的「摄像头语音输入 -> 意图识别 -> 穿搭 Agent -> 小米音箱播报」流程，从能用推进到建议更自然、更贴近中文用户日常决策。

当前先采用规则种子库，不做小红书、微博、抖音等社交平台自动爬取。原因是自动抓取会引入登录、版权、反爬和结果稳定性问题，不适合作为当天真实设备 demo 的主路径。后续可以人工挑选公开笔记或视频中的穿搭原则，脱敏后追加到同一规则结构。

## 当前运行实现

运行时代码：

- `backend/miloco/src/miloco/life/outfit_knowledge.py`
- `backend/miloco/src/miloco/life/recommender.py`

推荐器输入仍然保持原有接口：

- `occasion`：出行目的，例如通勤、上班、面试、踢足球、社交晚餐、视频会议。
- `weather`：天气或环境，例如下雨、闷热、偏凉、室内、夏天、南方。
- `preference_tags`：用户偏好，例如舒适、简洁、正式、运动。
- 视觉识别到的衣物列表：由摄像头短时采集和 MiMo 视觉理解产生。

推荐器输出新增：

- `rationale` 中的「匹配穿搭策略」和具体原因。
- `broadcast_text` 中的一句短策略，适合小米音箱播报。

## 规则矩阵

| 维度 | 已覆盖场景 | 建议策略 |
| --- | --- | --- |
| 天气 | 雨天、阵雨、有雨早晨 | 防滑、耐脏、快干、可脱换外层，避免拖地裤脚和怕水材质。 |
| 天气/季节 | 高温、闷热、南方夏天、沿海湿热 | 轻薄、透气、排汗、版型不过紧；室内空调可备薄外层。 |
| 天气/季节 | 偏凉、降温、大风、秋冬 | 内搭 + 中层 + 防风外层，便于室内外温差切换。 |
| 出行需求 | 工作、通勤、会议、客户、面试 | 保留一个利落锚点，如衬衫、西装外套、挺括长裤或干净鞋履；颜色克制。 |
| 组合场景 | 雨天见客户、雨天开会、闷热通勤后进会议室 | 鞋履和外层先解决防滑耐脏，进室内后上半身仍要利落，避免湿外套影响会议形象。 |
| 组合场景 | 天气不好、阴天或多云，通勤后见客户开会 | 不把模糊天气直接当成雨天；选轻便耐脏外层和稳定鞋履，进室内保持利落。 |
| 组合场景 | 南方夏季湿热通勤后见客户、广州/深圳闷热通勤后开会 | 贴身内搭轻薄透气，路上减少闷汗；进室内再用利落外层稳住客户会议形象。 |
| 出行需求 | 社交、约会、聚会、晚餐、朋友吃饭、饭局 | 一个亮点单品搭配基础色，兼顾精致和舒适；闷热天气下优先保留轻薄透气。 |
| 出行需求 | 踢足球、运动、跑步、健身 | 优先排汗、活动空间和鞋底抓地力，不选限制动作的单品。 |
| 出行需求 | 视频会议、线上沟通、室内空调 | 重点看上半身，领口、肩线和颜色要适合镜头，避免过密小图案；室内偏冷时外层要容易穿脱。 |
| 出行需求 | 旅行、出差、机场、高铁 | 舒适、耐皱、便于移动，鞋履和外层适合长时间步行和空调环境。 |

## 已验证样例

1. 「今天下雨天通勤上班」+「南方夏天闷热有雨」
   - 命中：雨天通勤、高温湿热。
   - 播报重点：防滑、耐脏、可脱换外层；轻薄透气。

2. 「今天出门踢足球」
   - 命中：运动出行。
   - 播报重点：排汗、活动空间、鞋子要稳。

3. 「视频会议」+「室内」
   - 命中：视频沟通。
   - 播报重点：上半身、颜色和背景区分度。

4. 「晚上和朋友吃饭，天气有点闷热」
   - 命中：社交晚间、高温湿热。
   - 播报重点：保留一个亮点单品，其余干净协调；材质和版型要轻薄透气。
   - 回归要求：不能退化成「今天出门」，不能混入会议场景。

5. 「下午视频会议」+「室内空调有点冷」
   - 命中：视频沟通、偏凉分层、工作会议。
   - 播报重点：优先讲上半身和镜头背景区分度；内部 rationale 保留利落锚点和可穿脱分层。
   - 回归要求：播报不能被通用工作会议或偏凉分层策略覆盖。

6. 「今天下雨还要见客户开会」
   - 命中：雨天客户会议，高温湿热可作为辅助环境。
   - 播报重点：鞋履防滑耐脏，上半身保持利落，外层进室内可脱换。
   - 回归要求：不能退化成通用雨天通勤，也不能混入社交晚餐策略。

7. 「南方夏天通勤有点闷热，等下还要见客户开会」
   - 命中：南方湿热客户通勤、高温湿热、工作会议。
   - 播报重点：内搭轻薄透气，进室内用利落外层稳住形象。
   - 回归要求：不能退化成雨天客户会议、雨天通勤或社交晚餐策略。

8. 「今天天气不好，通勤后还要见客户开会」
   - 命中：不稳定天气客户通勤、工作会议。
   - 播报重点：天气不稳定但未明确下雨时，选轻便耐脏外层，鞋子稳一点，进室内保持利落。
   - 回归要求：不能误用雨天客户会议、雨天通勤、南方湿热通勤或社交晚餐策略。
